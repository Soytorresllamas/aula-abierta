Administrar contenidos

Usa un token de acceso personal de GitHub para editar el aula. La sesión dura hasta que cierres o recargues esta pestaña.

Cómo obtener el token

En GitHub, crea un token de acceso detallado con Soytorresllamas como propietario. En Only select repositories elige aula-abierta-valientes y aula-abierta. En Contents habilita Read and write. Elige una fecha de vencimiento y pega el token en el campo de arriba.
